# 御剑飞行全方位测试提示词

> 适用模型：MiniMax H3  
> 推荐风格：高品质国漫仙侠、电影级 3D  
> 用途：系统测试御剑飞行中的剑尖/剑柄方向、足部支撑、惯性、转弯、俯冲、急停、落地、镜头可读性与角色一致性。

## 使用方式

- 将四个片段分别生成，不要一次性生成整段。
- 片段 B、C、D 优先使用上一片段尾帧作为参考图。
- 每段生成前，将上一段“结束状态”原样写入下一段的起始状态。
- 建议每段生成多个候选，动作结构验收通过后再拼接。
- 特效华丽程度不能覆盖剑尖、双脚、剑柄这三个关键结构。

---

## 片段 A：建立结构与起飞

### 片段职责

清楚建立人物、飞剑、飞行方向和足部支撑关系，完成稳定起飞。

### 生成提示词

```text
电影级高品质国漫仙侠 3D 动画。一位绝美成年仙子独自在壮阔云海之上的悬空仙台御剑起飞。她拥有精致自然的东方五官，乌黑长发盘成灵动仙髻，少量发丝自然垂落，身穿层次细腻的月白与浅青渐变仙裙，半透明轻纱披帛环绕双臂，银色发饰与玉佩微微发光。全程只有这一位仙子，人物容貌、发型、服装、身体比例和配饰保持稳定。

开场使用稳定的三分之四侧前方全身镜头，清楚展示一柄结构明确的青白色东方宽刃仙剑水平悬浮于仙子双脚正下方。剑尖始终朝向画面右上方的飞行方向，护手、剑柄和剑穗始终位于仙子身后。剑身纵轴与飞行方向完全一致，宽平剑面朝上，左右两侧锋刃朝外。

仙子双脚沿剑身纵轴前后错开，前脚朝向剑尖，后脚靠近护手。双脚悬浮于宽平剑面上方约五厘米，由一层薄而透明的青色灵气托层承载，不接触左右锋刃。她双膝微屈降低重心，骨盆与肩线沿剑身纵轴排列，身体稳定而优雅。

飞剑先在仙台边缘低空水平悬停。仙子确认剑尖方向后双手在胸前结印，飞剑沿剑尖方向缓慢离开仙台并平滑加速。长发、衣袖、披帛与剑穗统一向剑柄后方飘动，形成清晰的逆风拉线。剑尖前方产生细长锥形气流，剑柄后方拖出青金色长流光尾迹。所有尾迹只能从剑柄后方延伸，不能从剑尖前方喷出。

镜头保持三分之四侧前方全身跟拍，同时清楚展示剑尖在前、双脚在剑面上方、剑柄在后三个关键空间关系。飞剑、人物与灵气托层作为一个完整主体同步移动，相对位置保持固定。

空间锚点始终不变：剑尖位于飞行方向前端，剑柄、护手和剑穗位于人物身后，人物双脚沿剑身纵轴前后错开并悬浮于水平剑面正上方。
```

### 负面约束

```text
禁止剑柄朝向飞行前方；禁止剑尖朝后倒飞；禁止剑尖和剑柄在切镜后互换；禁止人物站在剑刃边缘；禁止脚掌被剑刃贯穿；禁止把飞剑生成成扫帚、冲浪板、滑板或无柄金属片；禁止人物跨坐剑柄、骑剑或抱住剑身；禁止剑身竖立或侧翻九十度；禁止飞剑与人物分别移动；禁止双脚打滑、穿模或与剑身融合；禁止无因悬空和瞬移；禁止正面遮挡镜头掩盖飞剑方向；禁止出现第二个人物、复制人物或多余肢体。
```

### 结束状态

```text
仙子已经稳定站在飞剑上方的透明灵气托层，双脚前后错开；飞剑近水平高速前进，剑尖朝画面右上方，剑柄和剑穗位于人物身后；仙子身体轻微前倾，长发、衣袖和披帛向后飘动；镜头位于三分之四侧前方，人物与完整飞剑同框。
```

## 片段 B：高速巡航与华丽仙术

### 起始状态

```text
严格继承片段 A 尾帧：仙子稳定站在飞剑上方的透明灵气托层，双脚前后错开；飞剑近水平高速前进，剑尖朝画面右上方，剑柄和剑穗位于人物身后；人物身体轻微前倾，长发、衣袖和披帛向后飘动；镜头位于三分之四侧前方。
```

### 片段职责

测试高速巡航、统一惯性、仙术展示以及华丽特效下的御剑结构可读性。

### 生成提示词

```text
严格保持上一帧人物、服装、站姿、飞剑结构和飞行方向不变。飞剑继续沿剑尖方向高速巡航，速度逐渐提升。仙子随加速轻微前倾，膝关节保持弹性微屈，双臂舒展保持平衡。长发、衣袖、披帛与剑穗统一向剑柄后上方飘动，所有运动部件体现同一股向前飞行的惯性。

剑尖前方持续产生锐利但透明的破云光锥，剑柄后方青金色流光尾迹逐渐加长。剑身表面浮现金色符文和月白色流光，沿剑身纵轴从护手流向剑尖；双脚下方的灵气托层始终薄而透明，不改变飞剑轮廓。云海沿剑柄方向高速后退，远处悬浮仙山与瀑布形成明显空间视差。

仙子双手连续变换两组清晰法诀。第一组法诀令数百片发光莲瓣从剑尖两侧分流，沿飞剑外侧向后掠过，再汇入剑柄后方的尾迹；莲瓣不能挡住剑尖、足部或剑柄。第二组法诀召出三条半透明青金水龙，水龙只在人物左右与上方平行伴飞，龙首统一朝向剑尖方向，龙尾统一拖向剑柄后方，不缠绕人物双脚和飞剑。

镜头从三分之四侧前方平滑过渡到纯侧面跟拍，持续展示剑尖在轨迹前端、仙子位于剑身上方、剑柄位于人物身后。短暂拉远至云海大全景，展示飞剑、水龙和莲瓣共同穿越云层；随后立即回到侧前方中全景，重新确认御剑结构没有变化。

整体画面华丽、绚烂、赏心悦目，青金、月白、粉紫三色粒子层次丰富，体积云和晨光形成电影级景深，但人物与飞剑轮廓始终清晰。

空间锚点始终不变：剑尖位于飞行方向前端，剑柄、护手和剑穗位于人物身后，人物双脚沿剑身纵轴前后错开并悬浮于水平剑面正上方。
```

### 负面约束

```text
禁止飞剑与人物向不同方向移动；禁止双脚滑动、交换前后位置或穿模；禁止流光从剑尖前方反向喷出；禁止水龙逆向飞行；禁止水龙或莲瓣遮挡人物面部、剑尖、双脚和剑柄；禁止法阵穿过身体；禁止特效把飞剑变成冲浪板；禁止人物容貌、发型、服装和配饰改变；禁止全屏白光、过曝、闪烁、镜头抖动和随机换镜。
```

### 结束状态

```text
仙子与飞剑完成高速稳定巡航，剑尖仍沿轨迹前端指向右前方，剑柄仍在人物身后；仙子双脚站位未变，身体轻微前倾；三条水龙平行伴飞，莲瓣与青金尾迹统一向后延伸；镜头位于纯侧面略偏前的位置，完整飞剑保持可读。
```

## 片段 C：转弯、爬升、俯冲与拉起

### 起始状态

```text
严格继承片段 B 尾帧：仙子与飞剑高速巡航，剑尖位于轨迹前端，剑柄位于人物身后；人物双脚前后错开并稳定悬浮于灵气托层；三条水龙平行伴飞，所有尾迹朝向剑柄后方；镜头位于纯侧面略偏前的位置。
```

### 片段职责

测试飞剑在多轴机动中的正确朝向、人物重心变化以及镜头连续性。

### 生成提示词

```text
严格保持上一帧的人物、飞剑、足部站姿和运动方向。伴飞水龙与莲瓣逐渐化为光点消散，避免遮挡后续机动。

飞剑首先执行一次平滑左转弯。剑尖先沿弯道切线向左偏转，飞剑随后向弯道内侧轻微横滚，横滚角不超过十五度。仙子的肩线、骨盆和身体重心随飞剑同向倾斜，双膝保持微屈，双脚在灵气托层上的前后位置不变。剑柄始终跟随在人物身后，长发、衣袖、披帛和剑穗沿弯道外侧向后飘动。转弯过程中剑身纵轴始终与飞行轨迹切线一致。

飞剑完成左转并恢复近水平姿态后，执行一段平滑爬升。剑尖沿连续弧线向上抬高，剑柄随轨迹位于后下方；仙子重心略向前脚移动，身体沿剑身方向前倾。镜头切到低机位侧前方仰拍，清楚展示剑尖向上、剑柄在后下方、双脚仍位于剑面上方。

飞剑穿过云层后立即进入一次连续俯冲。剑尖沿弧线下压约三十度，仙子屈膝降低重心，躯干贴近剑身纵轴。长发、衣袖和披帛向后上方拉直，剑穗从剑柄后方拖出长弧。俯冲过程中双脚始终悬浮于灵气托层，人物不能离开飞剑。

接近下层云海时，飞剑执行平滑拉起。剑尖先沿连续弧线抬升，剑身逐步恢复水平，仙子随后伸膝并恢复直立。拉起过程中不掉头、不侧翻、不瞬移。镜头从高空侧向跟拍拉起过程，最后切回三分之四侧前方中全景，确认剑尖、双脚和剑柄的空间关系仍然正确。

空间锚点始终不变：剑尖位于飞行方向前端，剑柄、护手和剑穗位于人物身后，人物双脚沿剑身纵轴前后错开并悬浮于水平剑面正上方。
```

### 负面约束

```text
禁止转弯时剑尖掉头；禁止剑柄朝向弯道前方；禁止同时执行大幅横滚、后空翻和急俯冲；禁止剑身翻转一百八十度；禁止把飞剑竖立成火箭；禁止俯冲时人物脱离飞剑；禁止拉起时无因瞬移；禁止脚部滑动、穿模和踩到左右锋刃；禁止镜头切换后交换剑尖与剑柄；禁止用云雾和全屏特效隐藏结构错误。
```

### 结束状态

```text
飞剑已经完成左转、爬升、俯冲和拉起，重新恢复近水平巡航；剑尖沿当前轨迹指向左前方，剑柄位于仙子身后；仙子恢复直立但双膝仍有弹性，双脚前后站位不变；衣物与剑穗统一向后飘动；镜头回到三分之四侧前方中全景。
```

## 片段 D：急停、落地与收剑

### 起始状态

```text
严格继承片段 C 尾帧：飞剑恢复近水平巡航，剑尖指向左前方，剑柄位于仙子身后；仙子双脚前后错开，悬浮在透明灵气托层上；衣物、长发和剑穗统一向后飘动；镜头位于三分之四侧前方。
```

### 片段职责

测试急停惯性、人物离剑、稳定落地和完整收势。

### 生成提示词

```text
严格保持上一帧人物、服装、飞剑结构和运动方向。前方出现一座漂浮于云海中的白玉莲台，飞剑开始减速接近。

飞剑执行一次急停。急停过程中剑尖仍朝向原飞行方向，绝不掉头制动。剑身前段轻微抬高，剑柄后方的流光尾迹迅速缩短。仙子双膝加深弯曲，髋部后移吸收惯性，双臂自然展开保持平衡。周围云雾、莲瓣和细小粒子继续向前掠过人物与飞剑，清楚表现尚未消失的惯性。双脚仍悬浮在灵气托层上，不提前离剑。

速度降至平稳后，飞剑沿浅弧线减速下降。距白玉莲台约半米时，飞剑恢复水平悬停。仙子先将后脚从灵气托层侧向移开并落在莲台上，再以前脚自然跟进，双脚完全离开飞剑后稳定站立。脚掌全程不能接触剑刃，离剑动作清晰、优雅并有完整重心转移。

仙子站稳后右手轻抬，飞剑继续保持剑尖在前、剑柄在后的结构，绕她身体外侧平滑飞行一周，随后剑尖朝上、剑柄朝下，以清晰连续的旋转动作缩小光效并收入背后剑鞘。方向变化必须通过镜头可见的完整弧线完成，不能突然翻转或消失。

结尾镜头从侧前方全身构图缓慢环绕至正面中全景。仙子站在白玉莲台中央，长发、衣袖与披帛逐渐回落，周身青金、月白和粉紫色粒子化作莲花星河缓慢消散。背景云海、霞光、悬浮仙山和远方瀑布构成华丽景深。仙子优雅收诀，露出宁静微笑，最后保持人物和完整莲台同框。
```

### 负面约束

```text
禁止飞剑在急停时掉头；禁止用剑柄朝前模拟制动；禁止人物在减速前突然落地；禁止双脚踩在剑刃上；禁止人物从飞剑上瞬移到莲台；禁止收剑时剑尖与剑柄突然交换；禁止飞剑无过渡消失；禁止服装、发型、面容和配饰改变；禁止多出人物、飞剑、肢体或手指；禁止全屏光效遮挡落地与收剑动作。
```

### 结束状态

```text
仙子已经双脚稳定站在白玉莲台中央，飞剑沿清晰弧线收入背后剑鞘；人物服装与外貌保持一致；灵气、莲瓣与霞光缓慢消散，镜头以正面中全景完成唯美收束。
```
