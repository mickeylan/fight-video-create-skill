# 荣耀多职业战术招式专项

## 来源、定位与使用边界

- 来源：用户提供并筛选确认的《全职高手》叶修及荣耀多职业招式、操作与协同战术描述，2026-09-05 分两批入库。
- 原始归属：战斗法师、剑客、神枪手、弹药专家、狂剑士、斩鬼及叶修 / 君莫笑式多职业战术体系；使用时仍须确认当前角色具备对应职业能力、武器形态和控制精度。
- 用途：提供能量弹道微操、战矛浮空与连续突刺、折线闪避、剑术连击、枪体术与狙击、百花式光影控场、双人繁花血景、鬼步拔刀、枪械位移控制、视野盲区走位、扇形弹幕、三点炮击、千机伞变形攻击、空中抓摔、后坐力移动、长兵器回身横扫、非等距压制和群体聚拢压杀的执行级动作。
- 分类：本文件保存具体身体路径、兵器操作、接触反馈和连续动作链，属于招式库。武器形态清单、转换耗时、占用部件、弹药与恢复状态仍由技能库 `07-模块化武器形态切换.md` 管理。
- 补全声明：招式名称与核心机制来自用户原始描述及用户确认的作品职业体系候选；下文的前置姿态、握法、脚步、受力顺序、结束姿态、衔接和门禁属于为动作设计可执行性所做的补全，不冒充原作逐帧事实。

## 共通执行规则

1. **职业与武器门禁**：战矛、枪械、炮筒、棍和千机伞形态不可无因混用。每次换形必须先解除旧形态占用，再形成新形态；前后手、枪口、矛尖和伞柄关系跨动作保持连续。
2. **浮空不是定身**：目标离地后继续受重力、上一击冲量、身体自旋和空气阻力影响。后续攻击只能改变其速度和方向，不能让目标无因停在空中。
3. **射击必须有弹着反馈**：每发子弹或炮弹都要有射向、命中/落空位置、目标局部响应和射手后坐反应。弹道效果不能替代枪口方向与身体承力。
4. **高速位移必须留路径**：Z 字抖动、遮影步以及月步、剃步等空中换位都要显示起点、至少一个转向点和终点；残影只能强化速度，不能代替脚步、支点或反作用力来源。
5. **控制来自连续结果**：押枪、伪连和一波流的控制力来自每次攻击对姿态、速度、朝向或站位的累积改变，不写成无接触的强制定身。
6. **短时长取舍**：单个 3—5 秒动作段通常只承担一种主要控制任务。若组合多个招式，上一招的结束姿态和目标状态必须直接成为下一招的前置条件。
7. **具名能力分工**：卫星射线、机械空投、死亡之门、六星光牢与鬼神盛宴的独立能力机制存放于技能库；本文件只保存角色在阵域、召唤物或射线前后的持械动作与走位，不重复能力状态。

## 一、龙抬头

### 1. 适用条件

- 角色具备将斗气凝成可离体巨龙形态、并在飞行中持续微调方向的能力。
- 主战距离为中远程；目标已根据初始直线或浅弧弹道做出横移、侧闪或藏入掩体后的判断。
- 场地在龙头变向侧留有足够弧线空间；狭窄空间应缩小龙形体积和转弯半径。

### 2. 前置姿态与发动

- 角色以一脚在前稳定重心，前肩朝向目标，肘部略屈，掌心向上或斜前；另一手可护住中线或完成细微控制指令。
- 斗气先从前臂与掌根汇入掌心，形成昂首巨龙虚影。龙头、颈、躯干和尾部依次成形，能量流向由尾至头，避免一帧完整闪现。
- 角色沉肩、送肘、翻掌将龙形推出；脱手瞬间掌根朝初始攻击线，龙头先加速，龙身与尾部随后拉直。

### 3. 飞行、变向与接触

- 巨龙先按可预测的直线或浅弧飞行，诱使目标向自认为安全的侧面移动。
- 当目标完成闪避起步后，角色用指尖、手腕或另一手做一次幅度很小但方向明确的上挑/侧引指令。龙头先猛然昂起，再向目标侧翼翻滚；颈部弯曲，龙身沿头部新轨迹逐节跟随，尾部最后甩过旧弹道。
- 龙头走出陡峭弧线，从目标视线外侧或护架死角重新扑咬肩背、侧肋或躯干，不从目标身体内部折返。
- 命中时目标接触侧先内缩并转肩，胸髋随后被带离原朝向；若被格挡，护架先偏转，双脚沿龙头切入方向滑移。

### 4. 结束姿态、衔接与可读点

- 龙形完成扑击后沿既有动量掠过、爆散或被角色收回，不在目标体内停留。
- 角色控制手保持到龙头完成转弯，再收掌进入追击；可衔接 Z 字抖动抢近、遮影步切盲区或远程补击。
- 可读重点是“初始弹道 → 目标闪避 → 细微指令 → 龙头先昂起翻转 → 龙身逐节跟随 → 侧面命中”，不得只给突然拐弯的光团。

### 5. 禁用条件

- 角色没有离体斗气塑形或弹道微操能力。
- 目标尚未做出避让，变向没有战术意义。
- 龙身整体同时折角、无弯曲传播，或变向后无接触结果。

## 二、Z 字抖动

### 1. 适用条件

- 用于冲刺中规避一条迎面直线或窄幅攻击；需要左右两侧各有至少一个落脚空间。
- 不适合覆盖整个通道的宽面攻击、持续追踪弹幕或湿滑到无法急停的地面。

### 2. 动作路径

- 角色沿正前方启动冲刺，头胸保持朝向目标，第一步建立前进速度。
- 来袭轨迹接近时，外侧脚斜向左/右前方落地，脚掌由外缘滚至前掌，膝髋屈曲吸收横向负荷；躯干只侧倾到能让开攻击，不把上身甩出控制区。
- 第二步由内侧脚交叉或并步回切，重心从第一落脚点迅速穿过两脚之间，向相反侧前方完成第二次折返。
- 第三步重新指向原前进轴并继续加速。三个落脚点组成紧凑 Z 形，整体仍向目标前进，不退回起点。

### 3. 结果与衔接

- 迎面攻击从第一或第二折点外侧擦过；角色在第三落点获得敌人侧线，可接突刺、短射、遮影步或近身控制。
- 高速视觉上可像身体轻颤，但脚下必须留下三个可辨落点、尘屑方向或重心折返，不以原地残影冒充换位。

### 4. 禁用条件

- 两次折返方向相同、没有 Z 形；角色脚步不落地却任意横移。
- 角色携带无法随身体快速改线的超重武器，且没有卸重或推进能力。

## 三、押枪

### 1. 适用条件

- 角色持可连续精确射击的枪械，目标已经浮空，且单发冲击足以微调目标而非贯穿或直接炸飞。
- 射手看得见预定落点，并具备控制射速、弹着点和后坐力的能力。

### 2. 持枪与射击节奏

- 双脚或空中支点先稳定射手自身；双手握枪，枪托抵肩或前臂形成稳定承力三角，躯干略向枪口方向压住后坐。
- 第一发命中目标靠近质心的胸腹或骨盆，先确认目标当前旋转和漂移趋势。
- 后续各发不打同一点：要把目标向右推，就依次命中左肩、左肋、左髋等质心左侧区域；要向左推则反向布点。要延长浮空，可在横移弹之间穿插一发略低于质心的向上推力弹。
- 射速均匀，枪口每次只做微小角度修正；每发命中后等待目标出现可读位移，再将下一发落点沿身体边缘连续移动，形成“弹着点移动 → 目标平移”的因果链。

### 3. 目标反馈与结束

- 命中侧肢体或装甲先收缩，躯干随后横移；目标允许轻微滚转，但射手必须用下一发修正，不能让身体永远保持直立。
- 到达预定区域后停止射击，让目标按剩余动量和重力下落；可衔接遮影步抢落点或三点炮封住落地方向。

### 4. 禁用条件

- 每发命中同一中心点却声称目标持续横移。
- 射手站姿和枪口完全不受后坐影响，弹药无限，或目标无质量地平移。
- 目标在有效射程外、被遮挡，或弹丸冲击远大于微调需求。

## 四、遮影步

### 1. 适用条件

- 近身或中近距离单体压制；角色的步频和转向速度至少不低于目标，且能读取其头部、肩线与视线转动。
- 场地必须允许围绕目标移动；背贴墙、狭窄通道或群体包围会显著限制此招。

### 2. 进入盲区

- 角色先用攻击、假动作或位移迫使目标把头与肩转向一侧，再从其另一侧外肩切入。
- 前脚落在目标侧后方，躯干贴近但保留一前臂距离，角色胸线始终大致垂直于目标视线，不站在正后方同一直线上等候。

### 3. 持续跟随

- 目标向左转身时，角色以前脚为轴向其右后侧滑步；目标反向回头时，角色立即换轴，沿肩胛外缘移动到另一侧盲区。
- 每次移动由目标的头部和肩线先动触发，角色脚步在目标视线扫到之前完成。可穿插短拳、枪托、短刃或低位点打，但每次攻击后立刻换侧，不在同一盲区连续站桩。
- 目标因背后受击先转肩，再带动髋与脚；角色利用其上下半身转动不同步的半拍继续藏线。

### 4. 结束与反制边界

- 可衔接伪连维持不规则压制，或在目标急转扩大时退出到武器有效距离。
- 目标靠墙、进行全周横扫、使用范围攻击或队友报位时，遮影步的盲区条件被破坏，角色必须格挡、后撤或更换路线。
- 镜头可从目标肩后保持角色在画缘短暂出现/消失，但空间位置必须可追踪，不能真正隐身或瞬移。

## 五、抖枪

### 1. 适用条件

- 使用可承受短时间高频点射或短连射的枪械；主要用途是扩大水平覆盖、封住横向闪避，而非提高单点精度。
- 射手需预留横向扇区并确认友方、障碍与弹药条件。

### 2. 发射动作

- 射手端平枪身，肩部与肘部先稳定主轴，枪托抵肩或双臂形成承力结构。
- 扣动扳机的同时，前手控制枪身，后手腕以小幅高频左右摆动枪口。摆幅从中心线逐渐扩至目标宽度，不以整条手臂大幅甩枪。
- 子弹按枪口左右摆动依次形成左、右两行交错弹着点；连续弹道展开成窄扇形，覆盖宽度约为原直线射击的一倍，但中心密度相应下降。

### 3. 反馈、收束与衔接

- 后坐力让枪口同时有轻微上跳，前手必须持续向下压回水平轴；若不修正，扇形会逐步上扬并失去目标。
- 目标横移时先被一侧弹线逼回，再遇另一侧弹线；落空弹应击中其退路或掩体，产生明确封线结果。
- 扇区完成后松开扳机，枪口回到中心线，可接押枪转为单体精确控制或三点炮扩大封锁。

### 4. 禁用条件

- 把抖枪写成随机散射、无枪口摆动来源的弹幕，或声称精度与覆盖同时无代价提升。
- 枪械射速、弹匣容量或散热无法支持所需射击时长。

## 六、三点炮

### 1. 适用条件

- 使用可连续发射三枚炮弹并能在每次发射间微调角度的炮筒；目标有左右闪避空间或正从中远距离接近。
- 三发炮弹应有可控引信、飞行速度或落点时差，使三条路线能在同一战术窗口合围。

### 2. 发射顺序

- 角色以肩、背与前后脚构成承力线，炮筒抵肩或由机械支架承托，炮口先指向目标当前中线。
- 第一发直飞目标当前位置或前进线，承担迫使其横移的任务；发射后后腿屈曲吸收后坐，前手立刻将炮口微调向左。
- 第二发略向左侧预判点发射，封住目标左闪路径；角色再以腰背和前手把炮口越过中心线微调向右。
- 第三发射向右侧预判点，封住目标右闪路径。三条弹道在空间中形成前方一点、后方左右两点的倒三角包夹，不要求炮弹凭空追踪。

### 3. 命中与结果

- 第一发迫使目标选边或抬起防御；第二、第三发分别压缩两侧出口。炮弹可按前后错时爆炸，使冲击波把目标推回三角中心，而不是三发完全同时遮住动作。
- 发射结束后炮筒有排烟、后坐复位和弹药状态；角色可接 Z 字抖动离开发射位或切换近战形态。

### 4. 禁用条件

- 三发从完全相同角度飞行却声称形成包围。
- 没有爆炸安全距离、近身贴脸发射，或炮筒后坐与角色体重完全无关。
- 目标没有可逃路线时仍用三点炮，导致三条弹道职责重复。

## 七、千机伞变形攻击

### 1. 适用条件与边界

- 角色明确持有可机械/能量变形的千机伞或同类复合武器，并已定义伞、矛/枪头、炮管等形态。
- 本条只记录“变形如何接入攻击”。完整形态表、转换耗时、占用部件、能量/弹药来源、过热与复位使用技能库 `07-模块化武器形态切换.md`。

### 2. 伞形转战矛突刺

- 角色握紧伞柄，先让伞面挡、拨或遮住目标视线；手腕沿突刺方向短促一抖，伞骨向中心折叠，伞面贴回骨架，伞尖沿中轴弹出长矛枪头。
- 折叠过程结束前，持伞手已收至腰侧，前脚同步踏入；枪头完全锁定后，后腿蹬地、转髋送肩，沿伞柄中轴完成直线突刺。
- 命中护架或躯干后，枪头先停、伞柄再传递压缩力，目标接触处后移；角色收回枪头或保持矛形继续追击，不能边刺入身体边无缝展开伞面。

### 3. 空中伞形转炮与后坐转向

- 角色跃起或被击至空中后，先收膝缩短转动半径，双手握住伞柄与伞骨根部。
- 手腕扭转使伞骨向后折叠并锁成炮管，炮口朝身体希望离开的反方向；炮管完全锁定后才开火。
- 炮口火焰和气体向后喷出，后坐力先推肩和双臂，再带动胸髋改变空中轨迹。角色用收腿、展腿和腰腹转动抑制无控自旋。
- 完成一次转向后停火，炮管散热或复位；可接月步或剃步完成小幅修线，也可切回近战形态准备落地。

### 4. 禁用条件

- 普通固定伞、固定长矛或固定炮筒无因变形。
- 旧形态仍占用同一部件时新形态已经完整出现。
- 开火方向与身体位移方向相同，或形态变化本身被当作无来源推力。

## 八、空中圆舞棍

### 1. 适用条件

- 角色与目标同时离地或从高差边缘进入下坠；角色能抓住目标衣领、甲带、肩部结构或对方兵器的可靠承力点。
- 抓点必须能承受目标重量和圆周拉力；普通松散衣料不能无条件承载重甲目标。

### 2. 抓取与建轴

- 角色接近目标侧上方，抓握手先扣紧衣领/武器，拇指与四指闭合；另一手可握棍柄、压住对手肩背或辅助锁紧抓点。
- 角色收肘把目标拉近自身旋转轴，同时屈膝收腹，利用双方下坠速度建立初始角动量，而不是伸直手臂后突然开始旋转。

### 3. 抡圆与摔砸

- 角色以肩关节和躯干转动带动抓握臂画圆，髋部反向调整保持自身轴心；目标头胸或被抓端先进入弧线，髋腿因惯性滞后甩开。
- 抡至下半圆时，角色逐渐伸臂扩大半径，使目标获得更高切向速度；到达朝向地面的释放点，角色松开抓握或顺势下压，将切向速度导向地面。
- 目标以背肩或侧躯干先接触地面，髋腿随后拍落；地面反馈沿接触点向外扩散。角色受到反拉与释重影响，沿圆弧切线向相反侧偏移或落地滚卸。

### 4. 结束与衔接

- 抓取、整圆、释放和落地结果必须一气呵成。摔砸后可接地面追击，但要先交代角色自身落点和抓握手释放。
- 镜头可从圆轴侧面显示完整圆弧，或从斜上方同时保留双方高度变化；不能只展示模糊旋转后直接切到坑洞。

### 5. 禁用条件

- 角色体重、力量或能力不足以改变目标轨迹，且无外部支点或动量优势。
- 抓点脱落、目标武器松手后仍无因维持圆周运动。

## 九、180 度横扫

### 1. 适用条件

- 使用长枪、战矛、棍、长柄刀或其他能承受横向挥扫的长武器；用于身后/侧后方威胁、近距离多目标或打断追击。
- 身后半圆内必须有挥扫空间，角色先确认武器尾端不会撞上墙体或友方。

### 2. 转身与挥扫

- 角色先以靠近目标侧的脚掌为轴，另一脚向后外侧撤成弧步；头部率先转向身后确认目标，肩线随后追上。
- 后手拉柄尾贴近腰侧，前手引导武器中段，髋部转动带动肩臂，使武器从一侧水平或微斜扫向另一侧，覆盖接近半圆。
- 武器尖端/重端速度最高，先接触外侧目标；枪杆或中段随后掠过近侧目标。残影可形成半圆光弧，但必须贴着实体武器的真实轨迹。

### 3. 接触、收势与衔接

- 命中腰腹、护架或兵器时，接触侧先折弯/偏转，目标沿扫击切线后退或旋转；角色手臂与枪杆出现反震，不能穿过重物继续匀速。
- 扫击结束后武器保留横向余势。角色顺势转步面对新方向，可接倒卷式反撩、直刺或继续拉开距离；落空时也必须随余势换步，避免背部暴露。

### 4. 禁用条件

- 仅旋转视角而身体、脚步和武器没有对应转动。
- 在不足武器长度的狭窄空间强行完成完整半圆，或一次横扫无衰减击飞所有质量不同的目标。

## 十、伪连

### 1. 适用条件

- 目标已因上一击产生可见的失衡、回防延迟或受击恢复窗口；角色能精确控制招式速度和间隔。
- 伪连是节奏控制方法，可由拳脚、短兵、长兵或射击执行，但每击仍须遵守对应武器距离与动作路径。

### 2. 节奏结构

- 第一击快速命中并制造明确僵直，例如护架回弹、胸口收缩或落脚中断。
- 第二击在目标刚开始恢复时立即接触，间隔短；目标只能完成半次抬臂或转肩。
- 第三击故意延迟半拍，角色用假动作、换步或收枪保持威胁，让目标误判连段已经结束并开始反击。
- 当目标重心前移或护架打开时，第三击/第四击突然落下，再次把其压回失衡。之后可使用“短—短—长—短”或“长—短—长”的变化，但每次长间隔都必须有诱导行为，不能只是双方停住等待。

### 3. 目标反馈与退出

- 目标在各击之间应出现不同程度的恢复尝试：抬手、落脚、转肩、吸气或反攻起步；下一击利用该动作尚未完成的窗口命中。
- 连段压力来自攻击始终压在恢复边缘，而非系统判定文字。若目标成功格挡、后撤出距离或以范围技反制，伪连立即中断。
- 结束时以一次击退、挑空、卸武或主动拉距形成清楚结果，可衔接遮影步或一波流。

### 4. 禁用条件

- 目标从头到尾完全静止、没有恢复动作或受力差异。
- 间隔随机但没有诱导、没有距离管理，也没有下一击利用前一反应。
- 把“系统不判为连击”当作影视动作本身，而不转化为可见节奏。

## 十一、一波流

### 1. 适用条件

- 面对多个可被击退、挑飞或改变路线的敌人；场地有一个可聚拢方向和可供角色绕行的外圈。
- 角色具备持续移动、范围控制与目标切换能力。重型固定目标或相互距离过远的敌群不适合直接使用。

### 2. 聚拢阶段

- 角色先沿敌群外缘斜向切入，不冲进完全包围中心；第一击挑飞/推退最近敌人，使其向预定聚拢区移动。
- 角色利用第一人的飞行或后退路线迫使第二人侧让，再从其外侧补击，将第二人推向同一方向。
- 对第三、第四目标重复“外侧进入 → 命中靠外一侧 → 推向中心”的原则。每次击退方向都指向同一聚拢区，不能把敌人向四面八方打散。
- 已被聚拢的敌人发生碰撞、绊倒或护架拥挤，进一步缩小彼此空间；这些结果为角色绕圈压制创造条件。

### 3. 环绕压制阶段

- 角色沿敌团外圈快速游走，保持自身不进入所有敌人的共同攻击中心；每到一个角度就攻击试图脱离的最外侧目标。
- 对前方脱离者用横扫或击退推回，对高位跳出者用挑击/射击压回，对倒地边缘者用脚步封线而非停下补刀。
- 敌群应持续出现碰撞、重叠护架、相互阻路和不同方向的恢复尝试；角色通过换位逐次处理，不让所有敌人同时静止挨打。

### 4. 结束与衔接

- 一波流可以在敌群被压缩成一个可控区域后交给范围终结技，也可以在关键目标暴露时切为单体追击。
- 结束前必须说明角色位于敌团哪一侧、敌群整体动量朝向何处，以及是否仍有敌人脱离；不可用“全部聚成一团”代替空间调度。

### 5. 禁用条件

- 一打一场景、敌群不可位移、场地没有聚拢空间，或角色没有足够机动性。
- 多个敌人排队等待攻击；角色每次击打方向互相矛盾，却无因形成整齐敌团。

## 十二、百龙流星打

### 1. 适用条件与起势

- 使用战矛、长枪或可高速回收的尖头长兵器；目标处于一枪身内，角色有半步至两步的追压空间。
- 前手控住枪身中前段，后手靠近柄尾；枪杆贴近身体中线，肩肘放松，前脚指向目标外侧，避免大幅枪花暴露连续刺击的起点。

### 2. 连续换点刺击

- 第一至第三刺以最短回收路线试探面门、前肩和胸口。每刺由后脚蹬地、髋肩短促前送，接触或被格挡后仅回收至能重新加速的距离，不把整枪拉回身后。
- 中段在双肩、肋腹和下盘间不断换点：真刺沿已打开的缝隙送入，虚刺在护架将要闭合前收回，诱导目标继续把防御移错方向。
- 角色用半步跟进维持枪尖有效距离；目标每次格挡都会让前臂、肩线或髋部产生不同偏移，后续枪路必须利用该偏移，不能对完全同一位置机械重复。
- 最后一刺减少花招，前脚稳踩，后腿完全蹬伸，转髋送肩把枪杆压成一条直线，沿已被拨开的中线完成全链最重的一击。

### 3. 受力与退出

- 轻刺使接触点短促后缩、护架左右摆动并让目标逐步退脚；若刺中质心下方可补充上升冲量，但普通力量不能把重型目标无因钉在空中。
- 终刺命中后，目标先在接触点塌缩，再由胸髋整体后移或被击飞；角色前肩和枪杆出现反震，必须收枪、换步或借横扫卸力。
- 可接豪龙破军扩大直线冲势；若对手成功贴住枪身，应立即转枪托或退出，不强行维持长距离连刺。

### 4. 禁用条件

- 枪尖没有独立回收和换点过程，只显示一团连续残影。
- 角色不追步、目标持续后退，却让每一刺保持相同入深。
- 目标从头到尾保持同一站姿，没有格挡偏移、局部受击或落脚调整。

## 十三、豪龙破军

### 1. 适用条件与蓄势

- 用于中距离直线破架和持续推退；前方必须有完整冲刺通道，角色与武器能承受正面反冲。
- 角色压低重心，枪尖对准目标胸腹或护架中心，前手锁定方向、后手抵住柄尾。斗气先沿手臂进入枪杆，再从枪尖向后包覆成龙形锋面，不能在角色尚未起步时凭空撞中目标。

### 2. 突进与持续承力

- 后腿第一次蹬地建立速度，前脚低位踏入；枪尖先接触护架并将其压向胸口，肩、背、髋保持同一推力线。
- 角色以连续短促追步维持推力，人与枪沿一条主轴推进。龙形锋面贴着枪尖和目标接触面向后翻卷，只强化冲势，不脱离武器独立绕飞。
- 目标最先在双臂或胸甲处受压，随后髋部后移、双脚犁地或交替退步；若撞上障碍，反力沿枪杆回传，角色必须屈肘沉肩或提前改线。

### 3. 结束与衔接

- 推进达到距离、目标护架被贯穿或通道将尽时，角色停止继续蹬地，枪尖上挑、横拨或收回，身体以斜向滑步卸掉余速。
- 可把目标推入斗破山河的震区、墙边或队友火力线；若目标侧闪成功，角色必须沿既有冲势掠过再转身，不能直角急停。

### 4. 禁用条件

- 狭窄断路、友方挡在突进线上，或枪尖无法承受正面撞击。
- 目标脚步和上身都不受持续推力影响，或角色没有追步却无限推进。
- 龙形锋面离开枪身单独追踪目标；该情况属于其他能量弹道能力。

## 十四、斗破山河

### 1. 适用条件与腾身

- 用于地面震荡、破坏落脚和掀起近处目标；地面必须能传递冲击，角色有跃起、举矛和安全落点空间。
- 角色先屈膝压低枪尾，再以双腿起跳；上升阶段双手沿枪杆换到便于下压的位置，把战矛举过头顶，腹背收紧控制枪身不过度后摆。

### 2. 下砸与冲击传播

- 下坠开始后，角色由髋部先折转，肩臂随后把枪尖或强化矛端导向预定落点；武器轴、双手和躯干重心保持在可承力平面内。
- 接触顺序必须是“矛端触地 → 枪杆压缩/反震 → 地表在落点下陷 → 裂纹、碎土与尘环向外传播”。冲击波沿地面而非在空中整圈凭空生成。
- 近处目标先因脚下地面倾斜、碎裂而失去支撑，膝髋抬起或侧翻；随后地表反冲把躯干掀离地面。距离越远，抬升和破坏越弱。

### 3. 收势与风险

- 角色屈肘、沉肩吸收枪杆反震，借回弹拔出矛端并侧向落步；若地面过软，武器可能陷入，必须以转柄或弃轴脱离。
- 可用豪龙破军穿过被震开的防线；不能在大范围冲击尚未结束时让角色无反馈站直。

### 4. 禁用条件

- 悬空平台、脆弱楼板或无法承受下砸的地面，除非明确表现塌落风险。
- 所有目标无视距离同时等高飞起，或地面先爆炸、武器后接触。
- 角色普通人体力量却制造远超能力档的大范围地形崩坏。

## 十五、伏龙翔天

### 1. 适用条件与发射

- 角色具备以战矛引导并释放离体龙形斗气的能力；用于中远距离直线贯穿、正面破架或把目标击离原位。
- 角色前脚定线，枪尖从腰侧沿目标中线前送；后腿蹬伸、转髋送肩，使枪尖达到最大延伸时释放龙头。龙颈、躯干和尾部依次从枪尖拉开，形成有前后传播的完整龙形。

### 2. 直线扑击与命中

- 标准版本沿发射时确定的直线或浅弧扑向目标，不自动追踪。龙头先撞上护架或胸腹，龙颈随后压缩，龙身继续传递推力，尾部最后甩过接触线。
- 命中时接触处先后缩，目标肩髋沿飞行轴后移；若护架未破，双脚应滑退或离地。能量散去后目标保留击退、滚转或下坠速度。
- 角色发射后枪尖仍指向主轴，前肩承受能量回冲；随后收矛护中或追步，不能一发出手便无因换到完全相反朝向。

### 3. 与龙抬头的边界

- 伏龙翔天负责形成并发射完整龙形；龙抬头只在龙形已经离手、目标依据初始弹道完成侧闪后，追加一次细微控制使龙头昂首变向。
- 若目标没有闪避或角色没有持续弹道微操能力，保持标准直线命中，不强行追加龙抬头。

### 4. 禁用条件

- 角色没有离体斗气塑形能力，或普通枪刺被夸大为独立巨龙。
- 龙头、龙身和龙尾同时出现并同时转向，没有形变传播。
- 发射线被友方或实心障碍封死，却无穿透设定仍强行命中。

## 十六、幻影无形剑

### 1. 适用条件与首击

- 使用单手剑或适合高速换线的长剑；目标处于近身至一步半距离，角色有绕向两侧的脚步空间。
- 第一剑为幅度较小的斜切或短刺，只用于碰出护架方向。角色前脚落在目标外侧，后手护住中线，剑锋接触后立即沿对方兵器或护臂边缘滑出。

### 2. 连续换侧与节奏升级

- 第二、三剑利用首击造成的偏转，从反侧横切、下撩或刺向肩肋；每一剑结束时剑尖不远离目标防区，手腕回正与换步同时完成。
- 中段以“左侧短斩 → 低线撩起 → 错身回切 → 转身追斩”逐级增加力量。目标每次转肩防守都会让另一侧短暂暴露，下一剑沿真实空隙进入。
- 攻击间隔由可辨的短停逐步压紧，但不能变成看不清接触的持续光幕；每剑都要显示剑锋方向、格挡或命中点以及目标恢复未完成的状态。
- 末剑由支撑脚扎稳、髋部完整旋转、肩肘延后追上，以最长有效剑路斩入已经崩开的护架，形成全链最大击退。

### 3. 反馈与结束

- 目标护架按左右、高低顺序被带偏，脚步为追随来剑不断交叉或后撤；命中侧衣甲、肩胸和髋部依次响应，不让目标在连斩中冻结。
- 最后一剑后角色顺势越过或停在目标侧前方，剑尖回到防线；可接剑影步重新切侧，或主动拉开避免末剑余势暴露背部。

### 4. 禁用条件

- 所有剑路来自同一侧、没有利用上一剑的护架偏移。
- 只显示大量残影和火花，实体剑、脚步与接触顺序不可追踪。
- 目标已经退出剑长或倒地，角色仍原地完成预设连斩。

## 十七、剑影步

### 1. 适用条件

- 用于高速接近、扰乱视线和切入侧后方；场地至少允许三条宽度不同的折线路线，角色具备足够急停与再加速能力。
- 残影是高速运动留下的视觉误导，不具备独立质量、攻击力或判断能力。

### 2. 步法与残影生成

- 角色先沿一条真实主线加速，在第一转向点以前脚掌斜踩、屈膝吸收横向负荷，躯干保持面向目标；换向后，原方向残留一个与离开瞬间姿态一致的短时影像。
- 第二、第三转向采用不同步幅和停顿：一条窄折线诱导目标锁定中央，一条更宽的侧切把真身移到外肩。每次残影只沿旧速度方向延续半步并衰减。
- 真身必须拥有连续的落脚点、尘屑或衣摆方向；目标的视线和兵器先追错一个残影，真身才获得侧后切入窗口。

### 3. 结束与衔接

- 最后落点位于目标侧前或侧后的一剑距离内，角色用外侧脚刹住横移，剑锋同时抬到可攻击线；可接幻影无形剑首击或一次明确的背侧短斩。
- 若目标使用全周横扫、范围攻击或退到墙边，残影误导条件被破坏，角色必须格挡或退出，不能以残影当实体盾牌。

### 4. 禁用条件

- 真身没有连续路径，在多个位置之间瞬移。
- 残影脱离旧轨迹主动包围、格挡或攻击目标。
- 角色携带超重武器、地面湿滑或空间狭窄，却仍无减速完成多次急折。

## 十八、枪体术

### 1. 适用条件与持枪

- 神枪手持短枪、双枪或适合贴身操作的紧凑枪械；必须确认近距离射击安全、弹药状态与枪口不会扫过友方。
- 枪械始终参与护线：前手枪控制对方兵器或视线，后手枪贴近肋侧准备短射；手指在枪口未指向有效目标前离开扳机。

### 2. 近身链

- 角色先以枪身或前臂向外拨开来袭手腕/兵器，前脚切入对手外侧；拨动只改变攻击线，不与重兵器硬顶。
- 利用护架被带开的半拍，以枪托短撞下颌、颧侧或胸甲上缘，接触后立刻收肘，目标头肩先偏转。
- 角色用同侧膝撞击腹部、髋部或大腿，破坏站姿；膝盖回落成为错身支点，身体贴着目标侧面转到肋后。
- 只有枪口与目标身体之间形成清晰安全线后才补一至两发短射。后坐从握把传至腕、肘、肩，角色用贴身结构压住枪口上跳；弹着点利用拳脚打开的缝隙，而非随意穿透身体。

### 3. 反馈与退出

- 拨枪改变对方攻击方向，枪托撞击造成头肩回弹，膝撞使骨盆后撤或单脚离地，补射再把目标从角色身侧推开；四种结果必须连续传递。
- 射后角色借目标被推开的距离退出到短枪优势区，或以遮影步保持盲侧；枪械卡壳、被抓住或空间拥挤时改用肘膝脱身，不无因继续射击。

### 4. 禁用条件

- 把徒手连招和站桩开枪并排拼接，前后没有护架与距离因果。
- 枪口穿过自身或目标身体才开火，或贴脸爆炸性弹药却无反噬。
- 每发射击无枪口方向、后坐和弹着反馈。

## 十九、巴雷特狙击

### 1. 适用条件与瞄准

- 使用重型狙击枪或等效高威力远射武器；角色有稳定支撑、清晰视线和足够安全距离，枪膛与弹药状态明确。
- 角色卧姿、跪姿或靠固定支点建立承力三角，枪托压紧肩窝，前手承托护木/支架，面颊贴托；呼吸减缓后在自然停顿窗口完成最后微调。

### 2. 发射与弹道

- 扣动扳机前枪口已指向装甲接缝、感知点或明确远距目标；击发瞬间先见枪口焰与枪机反应，再见肩线后移、枪口小幅上跳。
- 子弹沿单一可追踪弹道飞行，不中途转弯。目标移动时，枪口在击发前完成提前量；命中或落空由既定弹道决定。
- 命中装甲接缝时，局部先凹陷、破裂或迸出碎屑，冲量随后传过躯干，使目标猛烈后仰、旋转或横向抛移；不同质量目标的位移幅度必须不同。

### 3. 射后状态

- 射手肩臂吸收后坐并重新压回瞄准线，完成退壳、复进或换弹；尘土、枪口烟和听觉延迟不能代替真实枪械循环。
- 一发暴露位置后可立即换掩体，或接移动射击资料重建距离；不能保持完全相同姿态无间隔连续打出重型狙击效果。

### 4. 禁用条件

- 枪托未抵肩、无支撑却几乎不受后坐影响。
- 隔着不可穿透障碍无侦测依据命中，或子弹追踪目标转弯。
- 命中点与目标抛飞方向矛盾，或高威力弹只产生无质量火花。

## 二十、百花式打法

### 1. 适用条件与资源分工

- 弹药专家持有数量有限、功能明确的手雷、烟雾、闪光弹和特殊弹药；场地有可供爆点分层和角色换位的空间。
- 每种弹药只承担主要职责：烟雾遮视、闪光打断观察、爆破弹逼位、持续弹药封路。不能把所有效果堆进同一爆点。

### 2. 光影花幕建立

- 第一枚投向目标前进线或掩体出口，爆点迫使其减速/选边；第二枚以更高抛物线落到选择侧，封住继续横移；第三枚在另一高度或更深位置爆开，形成前后错层。
- 角色不站在花幕中心，而是沿每次爆炸照亮或遮暗的间隙侧移。枪口只从尚未被友方或浓烟遮断的窗口短射，射后立即换位。
- 爆点的亮度、烟尘和碎屑逐层叠加形成“百花”视觉，但每次爆炸都必须改变目标的视线、脚步、护架或逃线；漂亮光效不能取代战术结果。

### 3. 目标反馈与收束

- 目标先被第一爆点逼离原线，面对侧向爆点抬臂、转头或踉跄，再因弹着从未覆盖缝隙进入而继续换位；不可站在光幕中静止挨炸。
- 角色在弹药消耗到阈值前保留一条退出线，以最后一枚烟雾或爆破弹切断追击；可把目标逼入狂剑士的近身线，形成繁花血景。

### 4. 禁用条件

- 爆点随机铺满画面，没有封路、遮视、逼位或掩护职责。
- 角色本人看不见目标却持续精准命中，或友方穿过爆区不受影响。
- 弹药无限、烟雾跨镜消失、前后爆点不留下环境状态。

## 二十一、繁花血景

### 1. 双人职责与进入条件

- 弹药专家负责外圈光影花幕、封线和视野错乱；狂剑士负责借遮蔽进入、承接被逼出的目标并用重斩完成近身压制。
- 两人必须提前确定安全扇区、推进方向和退出口。弹药爆点不覆盖狂剑士的真实行进线，狂剑士也不能挡住远程射界。

### 2. 协同动作链

- 弹药专家先以一枚正面爆点迫使目标转向，再把第二、第三爆点布到其视线追随侧，形成短暂光暗交替；狂剑士从未被照亮的斜后缝隙压低身体冲入。
- 狂剑士第一记重斩击向护架外缘或持械臂，把目标推回预定爆区边缘；弹药专家不朝两人接触点射击，而是把下一发落在目标准备撤出的另一侧。
- 目标被爆点逼回后，狂剑士以踏步横斩或上撩继续压住近身；每次近战击退方向都与下一枚封路弹的空缺互补，形成“远程逼位 → 近战承接 → 近战推回 → 远程再封”的循环。
- 光幕最密时仍要保留双方轮廓、武器线和目标受力。狂剑士的剑风、血色气息或伤势强化只跟随实体斩击，不单独替代接触。

### 3. 收束与失配处理

- 终结由弹药专家封死最后退路，狂剑士把目标从未爆炸的安全缝隙斩出或击倒；随后远程停火，近战角色沿预定出口撤离。
- 若目标突入弹药专家近身、狂剑士被控或风向把烟幕吹回友方，两人必须中断循环、重新拉线，不强行维持协同图案。

### 4. 禁用条件

- 双方同时朝目标中心无差别倾泻，爆炸覆盖队友而无误伤风险。
- 光幕完全遮住狂剑士和目标的接触，只用颜色声称近战持续命中。
- 远近攻击方向互相抵消，却无因把目标固定在中心。

## 二十二、鬼影闪

### 1. 适用条件与鬼步进入

- 使用刀类武器，角色具备短时鬼步或等效高速低位掠行能力；用于穿过一条已判断的攻击线并在目标另一侧完成单次拔刀切线。
- 角色先压低髋部、刀柄靠近腰侧，前手可护住刀鞘或刀背；启动点与目标之间必须有清晰短直线，不能穿过实心障碍。

### 2. 掠行与拔刀

- 来袭攻击接近时，角色由后脚蹬地，身体贴地沿其下方或侧缘掠过。头胸略低于原攻击线，双脚仍有一次可辨的启动与一次终点落步。
- 接近目标侧面时，拔刀手沿行进方向拉出一条短而平的切线；刀锋通过目标轮廓后，角色继续前移半步，不在身体内部停刀。
- 高速残影只连接起点和终点，实体刀锋的方向、目标接触侧和角色终点朝向必须一致。

### 3. 延迟反馈与收势

- 角色在目标另一侧显形，前脚刹住、后脚补稳，刀锋仍保持切出后的余势并开始收刀。目标先因接触侧神经/护甲冲击出现短促僵顿。
- 半拍后斩痕沿原切线裂开，目标上身先错位、转肩或失去支撑，再沿剩余冲量倒下；“延迟”是命中反馈的时间差，不是刀锋隔空再次攻击。
- 可在终点接已有鬼阵的保护或撤离；若目标未被破防，角色必须面对其转身反击，不能依靠显形无敌。

### 4. 禁用条件

- 没有启动点、切线和终点，只表现角色从一侧瞬移到另一侧。
- 多个目标不在同一切线却同时出现相同斩痕。
- 斩痕方向与刀锋轨迹不一致，或角色收刀前无因改变朝向。

## 推荐组合与衔接

### A. 枪械封线换位链

`抖枪扩大水平覆盖 → 目标被逼向中心线 → 押枪控制浮空位移 / 三点炮封住两侧 → Z 字抖动离开发射位`

- 抖枪负责覆盖，押枪负责精确位移，三点炮负责路线包夹，职责不重复。

### B. 空中反冲抓摔链

`千机伞转炮改变空中轨迹 → 收枪贴身接近 → 抓住可靠承力点 → 空中圆舞棍整圆 → 沿切线掼向地面`

- 每次空中改线必须由明确的支点、步法或武器反作用力解释；抓摔后角色自身也要交代反拉、偏移或落点。

### C. 盲区节奏压制链

`Z 字抖动切过正面攻击 → 遮影步进入侧后盲区 → 伪连以短短长短节奏诱导回身 → 180 度横扫处理侧后增援或退出`

- 遮影步失效时应及时退出，不能把盲区压制写成永久隐身。

### D. 群体一波流

`从外缘切入 → 逐个把敌人推向同一聚拢区 → 环绕处理外逃者 → 压缩敌团 → 范围终结或切入关键单体`

- 多个敌人必须同时尝试移动与反击，不得排队。

### E. 伏龙翔天 + 龙抬头追闪连携

`战矛定线并释放伏龙翔天 → 龙形沿直线扑进 → 目标根据初始弹道向侧面闪避 → 操作者保持枪尖主轴并以指尖/手腕做微幅上挑侧引 → 龙头先昂首翻转 → 龙颈弯曲、龙身逐节跟随 → 从目标侧后死角完成追击`

- **连携触发条件**：必须先看见目标已经对伏龙翔天的初始直线作出横移、侧闪或绕障判断。龙抬头不是固定二段，也不在目标原地防守时无意义触发。
- **控制连续性**：伏龙翔天脱手后，施术者的控制手、枪尖或能量联系保持到变向完成；微操动作幅度小但方向可读，不能在角色完全收势后让龙形自行转弯。
- **形变连续性**：龙头先抬升并侧卷，颈部形成陡弧，躯干和尾部沿旧轨迹逐节被带入新线；禁止整条龙同时折成硬角。
- **命中因果**：追击从目标刚让出的侧面或背侧切回，接触侧肩背先内缩，胸髋再被推转；若目标二次闪避成功，龙形沿新轨迹掠过，不强制吸附。
- **结束状态**：龙形爆散或沿剩余动量飞离，目标保留被推转、击飞或下坠速度；施术者收矛并决定追步，不能命中后双方无因复位。

### F. 百花式打法 + 繁花血景协同链

`弹药专家分层爆点逼目标选边 → 狂剑士从未覆盖缝隙突入 → 重斩把目标推向下一封路线 → 弹药专家补封外侧而避开近战接触点 → 狂剑士承接回流目标完成终结`

- 两人的攻击职责、射界和安全扇区必须始终可读；任何一方失位，连携立即降级为掩护撤离或重新布线。
