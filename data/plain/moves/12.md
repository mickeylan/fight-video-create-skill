# 12-剑伞古刹地面回廊连招专项

## 来源与使用边界

- 用途：持长剑角色与伞类兵器角色在雨中庭院地面、回廊处的执行级攻防与环境连招；
- 原文提供动作名称、身体路径、接触和场景结果；下文对重心、衔接和适用条件的补全属于入库整理，不伪称传统武学定式。

适用于具备持械训练和较高机动能力的角色。伞必须有可承力伞骨、伞柄或钩状结构；普通雨伞、脆弱装饰伞或低强度写实任务不得硬接重剑。建筑破坏只用于夸张能力档。

## 角色动作签名

- **剑手**：以斜撩抢线、刺撩抹截连续压迫、剑身粘推改变伞面角度、低位平削追击落点、错身平斩终结；
- **伞手**：展开伞面竖架和偏转、收伞后用伞柄点刺；
- **距离关系**：展开伞面主守中距，收拢骨伞主战短距；长剑在剑尖距离压线，被伞面卡住后通过压剑、滑刃或换角重新夺线。

## 执行级动作与连招

### 1. 反手斜撩—竖伞卡锋

`剑手贴地突进 → 后手拔剑由下向斜上撩出 → 伞手侧后滑步让开身体中线 → 伞面竖起并以受力较强的伞骨接住剑锋 → 剑锋沿伞骨短滑并产生摩擦 → 双方手腕回弹，伞手借反作用力后翻或退入下一锚点`

- **攻击目的**：斜撩逼对手抬高防线并让出前进路线；
- **接触点**：剑刃中前段对外侧伞骨，避免剑尖无因穿过伞面；
- **反馈**：剑腕向外偏、伞柄压向肩侧、脚下水膜向相反方向炸开；
- **下一条件**：伞手获得后退或腾空动量，剑手沿同一方向追击。

### 2. 腾空旋身回旋斩

`伞手借上一格挡后翻拉开 → 剑手蹬地追起 → 空中收膝并转髋蓄转 → 腰腹带肩臂完成水平回旋 → 剑刃沿圆弧横扫伞手撤退线 → 伞手继续后翻、压伞偏转或改变高度`

- 旋身来自蹬地和收膝转髋，不写成空中无因连续自转；
- 以下锚点各是一个可画的定格姿态，相邻两个锚点之间只允许一个自由度在变：
- **起跳锚点**：先有可见下蹲、后脚蹬地，重心到最低点才离地，不允许身体平移到空中再开始转；
- **最高点锚点**：双膝收拢朝前、髋先于肩转动，躯干与起跳方向的夹角不超过 90°，剑仍在体侧未出手；
- **出手锚点**：出手发生在开始下落的瞬间，剑臂与躯干夹角不超过 90°、剑刃保持水平并指向圆弧切向；躯干在此段再转不超过 90°，整个腾空段的转体总量不超过半圈，禁止整圈及以上的连续自转；
- **落点锚点**：双脚或单脚落在起跳点前方固定位置，落地有可见屈膝缓冲，剑停在圆弧终点外侧而非身体正前方；
- 圆弧的圆心是伞手撤退线上的一个固定位置，不绕剑手自身中轴：这是绕前方定点的挥砍，不是原地自转；
- 剑手腾空期间，伞手只沿单一轴向后退步，或做不超过半圈的单轴后翻；后翻、压伞和改变高度不同时出现，一次只取其中一种结果；
- 手臂不做过顶绕环、剑刃全程可见且不绕到背后；收膝屈曲不超过直角、躯干前倾不超过三十度，避免身体缩成一团导致四肢粘连；
- 全景或低位跟随必须显示起跳点、圆弧轨迹和落点；
- 未命中时剑风切雨或削断檐角，证明攻击方向。

### 3. 刺—撩—抹—截四连追压

`直刺逼伞面正对 → 斜撩抬高伞缘 → 横抹沿伞缘切向持伞手 → 短截封住侧退路线 → 伞手以倾伞、竖架、侧滑和后退逐次化解 → 剑手转身把剑尖直刺在伞面上 → 刺中即收剑，重心下沉转为跃起重劈的蓄力`

- 四击共享向前追压动量，剑手步法沿回廊纵轴推进；
- 伞手每次防守改变伞面角度和脚步，不在原地重复抖动；
- 收尾的转身只用于把剑尖送到伞面上，转体不超过半圈；刺中是剑尖单点命中，伞面受一次正面推力后弹开，不写成剑身压住伞面或双方推顶僵持；
- 短链结束态为“剑尖刺在伞面、双方重心前倾、剑手已开始收剑”，收剑后直接跃起重劈，也可改由伞柄反击。

### 4. 收剑跃起—凌空重斩

`剑尖刺中伞面后收剑 → 剑手屈膝下压重心蓄力 → 前脚蹬地跃起 → 身体翻过接触线 → 双手或主手把剑从上向下重劈 → 伞手横伞硬架或侧移让重斩落在护栏/屋面`

- 起跳必须看见支点和离开接触点的瞬间；
- 收剑与跃起之间不出现新的推顶或僵持：伞面只承担刺击一次的受力，不承担起跳支撑；
- 重斩命中后出现剑臂下沉、伞骨弯曲、伞手膝胯降重心和脚步滑移；
- 环境破坏只沿剑刃落点发生。

## 合理性门禁

- 使用前检查伞的结构强度、角色握持、主战距离、可用支点、湿滑表面、建筑承重和目标时长；
- 本文件的四条动作可按照连续性和用户需求选择单条或数条成镜；
- 伞面、伞柄、伞骨和伞钩的功能转换必须通过展开、收拢、换握动作完成；
- 湿滑地面和护栏不是装饰，必须真实改变人物路线或攻击线；
- 本文件的动作不适宜做慢镜头，以平稳或快打镜头为主；
- 原稿的固定冲击帧、强动态模糊和极限时间数值属于表现参数，不是本招式成立条件。
