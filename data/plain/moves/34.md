# 电锯人爆炸推进与血雨攻势专项

## 来源、定位与使用边界

- 来源：用户从《电锯人》候选中筛选确认的蕾塞“爆炸推进—鱼雷肢体重击”“指弹火星”与血之恶魔帕瓦“千兆血雨”，2026-09-05 入库。
- 原作核心：蕾塞可从肢体释放爆炸强化移动与拳脚，可将肢体转成鱼雷状攻击，并能弹出接触后爆炸的火星；血之恶魔帕瓦可从周围血液生成大量剑与矛并投向敌人。
- 用途：提供由定向爆风解释的地面/空中机动、实体拳腿接触后的近身爆破、小型火星弹道，以及受血液库存约束的大规模实体兵器分层齐射。
- 分类：本文件只保存可落实为身体路径、爆点、弹道、接触和连续攻击的招式。变身方式、复活、血液恢复与其他独立能力不在本文件中扩写。
- 补全声明：角色、能力名称与核心机制来自作品设定；下文的发力顺序、姿态修正、目标受力、结束状态和门禁为动作设计执行化补全，不冒充原作逐帧说明。

## 共通执行规则

1. **爆点决定加速方向**：爆炸从身体一侧向外释放，人物沿反方向获得冲量。必须同时显示爆点、喷射方向、身体先受力部位和新轨迹。
2. **爆炸不等于无惯性飞行**：每次爆破只改变一次速度；连续改线需要新的爆点，脉冲之间身体继续受重力与已有动量影响。
3. **实体接触先于爆破**：鱼雷拳腿先完成肢体锁形、挥击和接触，再在接触点爆炸；不得以爆炸遮掉拳脚是否命中。
4. **潮湿是硬门禁**：蕾塞式点火与爆炸在身体、点火部位或火星被充分浸湿时失效或显著受阻。只有重新干燥或另有可靠点火源后才能恢复。
5. **血液必须守恒**：千兆血雨只能调用角色自身、场地中已经存在或世界观明确供应的血液。每批血兵器成形都会减少可用血量，破碎、刺入或飞离后不得无因回到库存。
6. **特效不能吞动作**：爆焰和血雨需要保留施术者肢体、目标轮廓、接触点、弹道层次与落点反馈。

## 一、爆炸推进—鱼雷肢体重击

### 1. 适用条件与起势

- 角色具备从手臂、腿部或躯干定向释放爆炸且能承受自身爆风的身体结构；若要使用鱼雷肢体，必须能让拳或腿完成可见锁形并在爆炸后恢复。
- 地面突进前先压低重心，支撑脚指向主路线；空中改线前收紧腰腹、缩短四肢转动半径，避免爆风把身体推入无控翻滚。

### 2. 定向爆炸推进

- 要向前冲，爆点设置在脚后、腿后或背侧。火焰和碎屑向后喷出，受力先传到爆点相连的腿/肩，再带动骨盆、胸腔和全身向前。
- 第一爆建立主速度；需要抬升时，第二爆转到脚底或下后方；需要横移时，爆点移到身体希望离开的反侧。每次爆破之间保留一段清楚的抛物线或斜线轨迹。
- 角色用展开一条腿、收拢另一条腿和反向转肩控制自旋。不得让同一个固定爆点同时推动身体前进、上升和急转。

### 3. 鱼雷肢体重击

- 接近目标前，将主攻拳或腿收回身体一侧，外形从近端向末端逐步锁成鱼雷状结构；另一侧肢体负责护住中线或平衡。
- 角色以转髋送肩完成直拳，或以支撑脚蹬转完成侧踢/下劈。鱼雷端先撞上护架、胸腹或可靠装甲面，目标接触处先凹陷，肩髋开始后移。
- 接触确认后鱼雷肢体爆炸，冲击沿原拳腿轴继续推送，并从接触点向外扩散。目标被实体打击改变姿态后才整体飞离，不能在拳脚尚未触及时提前爆飞。

### 4. 结束姿态与衔接

- 爆炸后的角色也保留反冲：地面攻击者后脚滑移或上身后仰，空中攻击者沿目标飞行方向的反侧偏离。必须用落步、下一次推进脉冲或翻滚重新稳定。
- 可在第一记鱼雷拳把目标击高后，以脚底爆炸追上，再用反向腿爆完成空中第二击；两次爆炸必须分别交代方向和目标新速度。
- 鱼雷肢体损坏、点火受潮或爆风把目标推出有效距离后，连段结束，角色不能无因贴回近身。

### 5. 禁用条件

- 角色没有爆炸免疫/耐受或定向爆破结构，却在贴身连续自爆中毫发无伤。
- 爆点方向与人物加速方向相同，或空中转弯没有新增反向爆点。
- 鱼雷肢体一帧出现、未接触先爆炸，随后又立即完整恢复。
- 爆炸覆盖整个画面，无法读取双方接触、受力与分离方向。

## 二、指弹火星

### 1. 适用条件与发动

- 角色具备从手指生成可独立飞行并在接触时爆炸的微型火星；点火手、空气路径和目标区域需要保持足够干燥。
- 拇指压住中指蓄势，手腕先对准预定落点；弹指时中指沿拇指边缘释放，火星从指尖脱离，而不是从画外或目标体内突然出现。

### 2. 弹道与战术用法

- 火星沿短直线或受重力轻微下坠的路径飞行，亮度足以追踪但体积保持很小。目标移动时，角色在弹指前给出提前量，火星本身不自动追踪。
- 第一发可打向目标前进线或掩体边缘，爆炸负责逼停和选边；目标开始侧闪后，第二发打向新落脚点，形成“落点爆破 → 目标改线 → 预判补击”。
- 若火星擦过潮湿表面、被水流击中或点火手完全浸湿，应熄灭、哑火或大幅削弱，不能照常形成满威力爆炸。

### 3. 命中反馈与结束

- 命中身体时先出现局部接触闪光，爆风随后推开接触侧肢体并带动胸髋转动；命中地面时碎屑与冲击沿落点向外扩散，把目标脚步逼离而非无因吸入。
- 连续弹指需要重新对准和完成下一次指部释放。发射后角色可借爆烟换位或接爆炸推进近身，但必须保留目标的新位置。

### 4. 禁用条件

- 只写“弹指爆炸”，没有火星生成、飞行、接触或落点。
- 火星绕开障碍自动追踪，或在完全湿透状态下无条件点燃。
- 多发火星无间隔从所有手指自动连射，且没有弹药、控制或姿态代价。

## 三、千兆血雨

### 1. 适用条件与血源门禁

- 仅适用于血之恶魔完整形态或明确具备同等级大规模血液塑形能力的角色；普通血液武器使用者不得直接调用千级数量。
- 发动前先确认场中可用血源的位置、体积和归属。血液从地面、伤口、容器或角色周围汇聚，不能从干净空气中无来源增殖。

### 2. 兵器生成与分层

- 血液先分成大量独立长条，靠近施术者的一端增厚为握柄/杆身，远端收尖或展开刃面，逐步形成剑、刀与长矛；禁止所有兵器一帧完整闪现。
- 成形兵器按距离分成前、中、后三层，并保留横向宽度、上下厚度和前后纵深。前层对准目标正面，中层向两翼展开，后层维持补位和二次射击。
- 施术者以抬臂、展爪或身体前倾给出发射指令；前层先加速，中层随后沿不同角度进入，后层根据目标闪避方向填补缺口，不能所有兵器机械同步。

### 3. 齐射、命中与目标反馈

- 第一波直射负责压住护架或迫使目标选边；第二波从两侧交叉封线；第三波只向尚未覆盖的空间补射，避免同一点无意义堆叠。
- 血兵器命中后应刺入、折断、碎回血液或随目标飞出。目标先由局部穿刺和格挡承受冲击，再因连续不同方向的命中失衡、跪落或被短暂压住。
- 落空兵器继续击中地面、墙体或远处，不在目标身后急转回来。若世界观允许回收，必须先碎解为可见血液，再沿明确路径回流。

### 4. 终止与衔接

- 可用血量下降到阈值、施术者失去控制、血源被凝固/蒸发或目标脱离射界后，剩余兵器停止生成；已发射兵器继续按原动量飞行。
- 收束时交代施术者剩余血量、空中尚存层数、落地兵器和目标状态。不能齐射结束后场景立即恢复干净。
- 与招式库 `07-万剑诀雷域箭雨专项.md` 的边界：普通御剑、剑阵和可回收飞剑群使用07；只有血液来源、塑形耗量和血兵器消耗构成核心时使用本条。

### 5. 禁用条件

- 普通人形态、血源不足或没有群体控制能力却直接生成千级兵器。
- 血兵器全部处于同一平面、同一高度、同一时间机械齐射。
- 特效遮住施术指令、兵器层次和目标受击，或目标在密集命中中完全静止。
- 已破碎和耗尽的血兵器跨镜无因恢复。

## 推荐组合与衔接

### A. 爆破追击链

`指弹火星炸向前进线 → 目标侧闪 → 反侧肢体爆炸推进 → 鱼雷拳/腿实体命中 → 接触点爆炸把目标送离 → 新爆点调整自身落点`

- 指弹负责逼位，推进负责缩短距离，鱼雷肢体负责实体接触后的终结；三段爆炸职责不能混成同一团爆光。

### B. 血雨分层压制链

`确认血源 → 三层血兵器逐步成形 → 前层压正面 → 中层封两翼 → 后层补逃线 → 停止生成并保留场地残留`

- 若与近战队友协同，必须预留一条不被血兵器覆盖的进入和退出走廊。
